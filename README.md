IOT BETA — RESPONSIVE STATIC WEBSITE

Pages
- index.html — Home
- projects.html — searchable project portfolio
- community.html — community and idea wall
- certificates.html — certificates (original image assets were not included in the supplied ZIP)
- work.html — My Work
- shop.html — project shop
- about.html — About
- contact.html — Contact / enquiry

Run locally
Open index.html in a browser. No build step or package installation is required.

Deploy
Upload the complete folder to any static host (GitHub Pages, Netlify, Vercel or traditional hosting). Keep style.css and site.js beside the HTML pages.

Notes
- index-1.html has been renamed to index.html and the original broken homepage markup has been rebuilt.
- Navigation links consistently point to index.html.
- Mobile navigation, responsive layouts, keyboard focus styles and reduced-motion support are included.
- The Projects page includes live text search.
- Contact form opens the visitor's email application; it does not store messages on a server.
- Update contact details, YouTube URL, shop pricing/order links and certificate images before publishing.
- Google Fonts are optional; the site has local system fallbacks.
